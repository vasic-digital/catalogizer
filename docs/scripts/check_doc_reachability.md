## Purpose

Constitution 11.4.212 makes the root `README.md` the entry point of all project documentation. This gate follows inline Markdown links from
`README.md` and lists every in-scope `.md` file (tracked files under `docs/` and `catalogizer-androidtv/docs/`) that no link path reaches.

## Usage

```bash
scripts/docs/check_doc_reachability.py [--root DIR] [--baseline FILE] [--tracker-root REL]... [--list] [--strict] [--update-baseline]
```

- Counted links: inline, reference-style (`[t][ref]`, `[ref][]`, `[ref]` with a definition) and `<a href>`. Ignored: HTML comments, inline code, ``` / ~~~ fences, indented code blocks.
- Headline caveat: 1778 of 2456 in-scope files (72%) are reachable only through the `docs/issues` tracker-root rule; the summary line prints this share.
- The baseline may only shrink: in a git checkout it is compared with the baseline at `--baseline-ref` (default `HEAD`) and any added entry fails; `--update-baseline` refuses to add entries.
- A link to a directory resolves to its `README.md`; a link to `docs/issues` (the default `--tracker-root`) covers every ticket below it.
- Baseline = list of tolerated orphan paths. An orphan not in the baseline fails (exit 1). `--update-baseline` only shrinks it. `--strict` ignores it.
- If `README.md` does not link `docs/README.md` the gate prints `ENTRY-LINK-MISSING` and uses `docs/README.md` as an extra root.
- Exit 2 = BLIND: empty scope, no `README.md`, no links parsed, or a failed built-in control. Controls run the real parser and walk on synthetic input: a synthetic linked doc must be reached, an unlinked one must not, and links hidden in comments, code and fences must not be found.
- Only tracked files count (`git ls-files`); commit new docs before running.

## Tests

`scripts/tests/test_check_doc_reachability.sh` runs golden-good, golden-bad, baseline, baseline-growth (git fixture), tracked-vs-untracked (git fixture), hidden-link, reference-link, tracker-root, BLIND and strict cases, then paired mutations (orphan detection disabled; baseline-growth check disabled; comment-stripping disabled), each of which must make the suite fail.

The per-directory indexes are regenerated by `scripts/docs/gen_dir_indexes.py` (config `scripts/docs/dir_indexes.tsv`, description overrides `scripts/docs/index_description_overrides.tsv`; `--check` is a drift check); test `scripts/tests/test_gen_dir_indexes.sh`.
