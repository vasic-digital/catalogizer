Class definition

A site is in the class when text derived from an error value can reach a client (HTTP, WebSocket or SSE response body or header) by ANY path. Routes (rework 3 widens this; the earlier definition excluded server-side state that is persisted and later served): (1) err.Error() or %v/%w/%s of an error inside a response call; (2) a bare error passed to a helper that serialises it; (3) error text stored in a struct or map that a handler later serialises; (4) error text kept in a variable and used in a response; (5) error text returned from a helper into a response; (6) a helper called inside a sink argument (gin.H{"e": scrub(err)}); (7) %v/%s of an error-typed identifier without .Error(), whatever the identifier is called; (8) error text stored in a struct field, map, database row, session or status object and served later by another route (Class 4); (9) error text published on the event bus and forwarded to WebSocket or SSE clients. Sites that only log or branch on text are outside the class; sites that record text in server-side state are IN the class when a route serves it, and are traced in Class 4.

Classes used in the tables: LEAK (internal detail can reach the client: SQL/driver text, wrapped %w chains, paths, upstream or JWT parse text; "can include", not a demonstrated leak for every row: service and repository strings were read only where stated); VALIDATION (authored text that tells the caller which input to fix, or a sentinel's own text; may echo the caller's own input); LATENT (leaking code that no non-test caller can reach); SAFE (the err value does not reach the client: log-only, fixed-text helper, or a non-client sink); CLOSED-BY-HELPER and CLOSED are HEAD statuses, not classes.

Classification rules (how the 20 old UNKNOWN rows were resolved)

Rule 1: a 4xx/5xx text produced by a service chain that contains fmt.Errorf("...: %w", repoErr) is LEAK (configuration GetWizardProgress, error_reporting GetErrorReport/GetCrashReport, auth Login/Refresh/ChangePassword via auth_service.go wraps, localization Import/Edit). Rule 2: text from a package-level sentinel or a smartrules.ValidationError is VALIDATION (playlist, service_handlers, conversion). Rule 3: ErrLocalRootNotAllowed text from ResolveLocalRoot/CheckLocalRoot is LEAK (it embeds cannot resolve path: <OS error>, local_policy.go:54). Rule 4: a binder (ShouldBindJSON) error on 400 is VALIDATION (mild: names Go struct fields). Rule 5: any other text on a 5xx or a variable status is LEAK.
