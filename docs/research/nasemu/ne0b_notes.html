1. Synology API contract (source: Synology_File_Station_API_Guide.pdf from cndl.synology.cn, fetched 2026-11-13, 502145 B)

Doc is "Synology File Station Official API", marked proprietary (no reproduction/design-basis without permission): contract notes below are paraphrased minimal facts for interop; legal use as shim basis = UNCONFIRMED/operator question. NOTE: URL https://help.synology.com/developer-guide/integrate_dsm/web_authentication.html is actually "Application Authentication" (package CGI authenticate.cgi), NOT the Login Web API. It only confirms login URL form /webapi/auth.cgi?api=SYNO.API.Auth&version=3&method=login&account=..&passwd=..&format=cookie, ports 5001 https / 5000 http, logout version=1&method=logout. The separate "DSM Login Web API" PDF was NOT found/opened (UNCONFIRMED). Request form: GET /webapi/?api=&version=&method=[&params][&_sid=] (or cookie id); params escaped (comma->\... per doc); passwd not escaped; POST also accepted for upload. Response: JSON {"success":true,"data":{...}} or {"success":false,"error":{"code":N[,"errors":[...]]}}.

  • SYNO.API.Info v1, since DSM 4.0, fixed at /webapi/query.cgi, method=query&query=all|comma-list -> data{:{path,minVersion,maxVersion}}. Doc examples: SYNO.API.Auth path auth.cgi min1 max3; SYNO.FileStation.List path FileStation/file_share.cgi (old v1 example); File Station v2 APIs (DSM 6.0+) use /webapi/entry.cgi. No API-specific error codes.
  • SYNO.API.Auth: v3 since DSM 4.2, v2 since 4.1. login params: account, passwd, session (e.g. FileStation), format=cookie|sid (v2+), otp_code (v3, reserved; "WebAPI doesn't support it yet"). Response data.sid. sid expires 7 days default. logout params: session; empty success. Errors: 400 no such account/incorrect password; 401 account disabled; 402 permission denied; 403 2-step code required; 404 2-step code failed.
  • Common error codes: 100 unknown; 101 no API/method/version param; 102 API does not exist; 103 method does not exist; 104 version unsupported for functionality; 105 session lacks permission; 106 session timeout; 107 session interrupted by duplicate login; 119 SID not found. File-op common: 400 invalid param; 401 unknown; 402 system busy; 403 invalid user; 404 invalid group; 405 invalid user and group.
  • SYNO.FileStation.Info v2 (DSM 6.0+) method get (no params), entry.cgi -> data{is_manager,support_virtual_protocol e.g. "cifs,nfs,iso",support_sharing,hostname}.
  • SYNO.FileStation.List v2: list_share (offset,limit,sort_by,sort_direction,onlywritable,additional[real_path,owner,time,perm,mount_point_type,sync_share,volume_status]) -> {total,offset,shares[{path,name,additional}]}; list (folder_path req; offset,limit,sort_by,sort_direction,pattern,filetype file|dir|all,goto_path,additional[real_path,size,owner,time,perm,type]) -> {total,offset,files[{path,name,isdir,additional{size,time{atime,mtime,ctime,crtime seconds},owner{user,group,uid,gid},perm{posix,...},type=extension}}]}; getinfo (path JSON-array string) -> files[]. additional passed as JSON array string e.g. ["real_path","size"]. (isdir field inferred from doc object; exact field table partially read: UNCONFIRMED line-level.)
  • SYNO.FileStation.Download v2 method download: path=["/share/f.txt"] (JSON array, URL-encoded), mode=open|download; one file -> raw content, many -> ZIP; no API error codes; with mode=open errors give HTTP 404.
  • SYNO.FileStation.Upload v2 method upload: POST /webapi/entry.cgi multipart/form-data (RFC 1867), parts api,version,method,path (dest folder starting with share),create_parents,overwrite(true/false; v3 overwrite|skip),mtime/crtime/atime (ms), file part LAST. Success: empty success. Errors: 1800 no/mismatched Content-Length; 1801 client wait timeout (3600s); 1802 no filename in last part; 1803 connection cancelled; 1804 oversized file to FAT; 1805 cannot overwrite/skip existing file when no overwrite param. Shim implication: minimal set = Info.query, Auth.login/logout (+ error 400/402/105/106/119), FileStation Info.get, List.list_share/list/getinfo, Download.download, Upload.upload. 2FA(403/404) not testable via official WebAPI per doc.
